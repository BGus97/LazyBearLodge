# Lazy Bear Lodge — Investor Landing Page

Single-page listing site for Lazy Bear Lodge, a short-term rental property in Coal Creek Canyon, CO.

## Files

- `index.html` — the full website (all CSS and JS are inline)
- `hero.jpg`, `exterior2.jpg`, `firepit.jpg`, `gameloft.jpg`, `greatroom.jpg`, `living.jpg` — property photos

## Viewing Locally

Just open `index.html` in any browser. No build step or server required.

## Hosting

Deployed via GitHub Pages. To update, replace any file and commit — the site rebuilds automatically.
